# Mein Tag 💧🍽️💪

Persönlicher Tracker (Web-App) für Kalorien, Wasser, Gym und Gewicht – fürs iPhone, komplett auf Deutsch.
Alle Daten bleiben lokal auf dem Gerät (kein Login, kein Server), die App funktioniert offline.

**App öffnen:** https://jm2mmw5kwr-code.github.io/animated-succotash/

## Zum Home-Bildschirm hinzufügen
1. Link in **Safari** öffnen.
2. Unten auf **Teilen** (Quadrat mit Pfeil nach oben) tippen.
3. **„Zum Home-Bildschirm“** wählen → **„Hinzufügen“**.

## Erinnerungen
Die Anleitung für die Kurzbefehle-App steht in der App unter ☰ → **Erinnerungen einrichten**.

## Dateien
- `index.html`, `style.css`, `app.js` – die App
- `manifest.json`, `sw.js`, `icons/` – damit sie wie eine echte App installiert werden kann und offline läuft
